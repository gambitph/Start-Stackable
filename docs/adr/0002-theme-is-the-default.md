# Theme is Default

Start Stackable must be a complete, designed block theme with Stackable off.
That first-activation site is **Default**.
It is not a kit package and it is not imported.

Site Kits live in the Stackable plugin: multi-page import, theme styles overlay, Global Design System, Design Library, block controls.
The theme zip never imports content, never ships a kit wizard, and never auto-imports on activate.

First paint is a designed post grid plus chrome (`index.html`).
Do not ship `front-page.html`.
A marketing landing in `home.html` fights Settings → Reading once a static front is set, and it duplicates kits.

One core-block Homepage starter pattern may live in the theme so a user can assemble a marketing page without the plugin.
Section catalogs (heroes, pricing, testimonials) stay in Design Library.
